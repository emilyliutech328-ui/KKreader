# 轻风阅读 · 1.0 版本说明

> 版本号：`1.0.26.102613`
> 包名：`io.qingfeng.reader.release`（与 KK读书 `io.lanying.reader` 完全隔离，可同时安装）
> 产物：`轻风阅读-1.0.26.102613.apk`，18.94 MB

## 本次改动

### 1. 立体书架：书籍上浮收窄，不再顶出画框

原实现里上浮量是 `coverWidth * 0.84f`，而书脊高度约为书架高度的 72%，
两者相加会超出控件顶部——书顶被裁掉一截。

现在：
- 上浮量改为 **书脊高度的 42%**，并按"书架区顶部剩余空间"二次夹紧；
- 书脊高度上限从 `shelfBottom * 0.72` 提到 `0.78`，等比例放大但整体不越界；
- `drawBookVolume` 里对 `pull` 再做一次 `min(到书架区顶, 到控件顶)` 夹紧，
  保证任何缩放/滑动状态下书顶都 `>= 0`。

结论：书的最高处始终在控件内，不再被框架裁切。

### 2. 立体书架与列表之间：书名信息 → 虚线区域

原来轮播下方有 104dp 的信息块，显示"当前选中书"的书名（两行大字）+ 作者/来源/章节数 + 翻页页码。

现在换成一条 **46dp 的虚线圆角框**：
- 左边「全部图书」，右边「N 本」（当前书架总数）；
- 虚线框用 `DashPathEffect` 画，提示"下方是完整列表"；
- 轮播控件高度相应从 340dp 收窄到 **300dp**，把空间还给列表。

单本书的书名不再在轮播里重复显示（书脊上本来就有竖排书名）。

### 3. 竖排 / 对页：不实现

按要求不做，保持 legado 原有的横排排版体系。

### 4. 内置在线书库：整块移除，只留一条默认书源

删掉的东西：
- `ui/store/`（书城界面、适配器、分类对话框、ViewModel）
- `model/wenku8/`（本地书目索引、详情解析器）
- `assets/wenku8/catalog.tsv`（3147 本书目索引，2.4 MB）
- `activity_store.xml`、发现页"书城"菜单入口、Manifest 注册
- 20 条书城相关字符串（四个语言）

保留的东西：
- `assets/defaultData/wenku8Sources.json` —— **内置书源「轻小说文库」**

现在它的定位就是一条普通的默认书源：首次启动时自动导入到书源列表里，
之后和别的书源一样可以搜索、可以编辑、可以删除、可以停用。不占用任何额外界面。

> 注意：因为站点对未登录访客关闭了列表/搜索接口，这条书源主要用于
> **打开已知的书页链接**（详情/目录/正文都能正常读）。如果你需要站内搜索，
> 需要在书源里登录，或自行导入其它书源。

### 5. 改名为「轻风阅读」+ 新版本线

| 项目 | 旧 | 新 |
|---|---|---|
| 应用名 | KK读书 | **轻风阅读** |
| applicationId | `io.lanying.reader` | **`io.qingfeng.reader`** |
| namespace | `io.legado.app` | 不变（改了会导致全量 import 失效） |
| versionCode 基数 | 10000 | **20000** |
| versionName | 3.x | **1.0.x** |
| 产物名 | `lanying-reader_app_*` | `qingfeng-reader_app_*` |
| 归档名 | — | `qingfeng-reader` |

应用名四份语言都改了：`values`/`values-zh` → 轻风阅读，`values-zh-rHK`/`values-zh-rTW` → 輕風閱讀，
`es/ja/pt/vi` → QingFeng Reader。

签名沿用同一把密钥（`lanying-reader.jks`），所以可以和 KK读书 并存安装，互不覆盖。

### 6. 订阅收藏页：加了使用说明

订阅（RSS）页顶部新增一个**可折叠说明面板**：

- 首次进入默认展开，之后记住用户的折叠状态（`PreferKey.rssGuideExpanded`）；
- 点击头部展开/收起，右侧显示「展开 / 收起」；
- 内容覆盖六块：订阅源是什么、怎么添加、阅读与收藏、搜索与分组、为什么是空的、收藏只在本机要备份。

说明面板放在标题栏下方、列表上方，不占用列表可视区域时会自动让位（列表 `constraintTop` 跟随面板）。

## 需要你确认的两点

1. **书源现在是"孤零零一条"**。因为站点关了搜索，它只能在已知书页链接时直接打开。
   如果你希望它还能站内搜索，需要：在书源里配登录信息，或者我把它改成也能读站内 sitemap 的思路（但那样又要引入一个后台抓取，和你"去掉书库"的意图相冲突）。
2. **订阅说明的文案**是我按 legado 的 RSS 功能写的（订阅源管理、分组、星标收藏、备份）。
   如果你实际用的时候发现有哪块功能和文案对不上，告诉我具体哪条，我改。
