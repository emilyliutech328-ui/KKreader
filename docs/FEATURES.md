# 轻风阅读 · 功能全景与界面优势

> 版本：1.0.26.102613
> 定位：Kotlin 原生 · 本地优先 · 无广告 · 自带书源引擎的 Android 阅读器
> 本文依据源码逐项核对，不是按记忆罗列

---

## 一、功能全景

### 1. 书架

| 能力 | 说明 |
|---|---|
| 两种书架样式 | 「样式一」按分组分页签 + 顶部立体书架；「样式二」可进入分组层级的书架 |
| **立体书架** | 3D 书脊轮播、弧形排布、封面/顶面/书脊三面绘制、惯性吸附、触觉反馈、按真实书本厚度错落 |
| 布局切换 | 列表 / 2 列 / 3 列 / 4 列 / 5 列网格，每列宽度与边距可调 |
| 排序 | 默认（阅读时间）、最近更新、书名、手动、综合、作者 |
| 分组 | 多级分组，每个分组可独立设置是否刷新、是否只显示未读、排序方式 |
| 性能开关 | 「按设备性能自动简化 · 当前档位」——低配自动隐藏立体书架并关模糊，中配收敛动效，高配全开 |
| 批量整理 | 多选后移动分组、移出书架、删除、更换封面 |
| 快速滚动 | 可选开启右侧快速滚动条 |

### 2. 阅读器

| 能力 | 说明 |
|---|---|
| 排版 | 字号、行距、段距、字距、首行缩进、对齐、页边距（四边独立）、字重、字体 |
| 字体 | 内置字体 + 导入 TTF/OTF 自定义字体 |
| 配色 | 阅读器独立配色、文字色、背景（纯色/图片/纹理）、背景透明度、护眼模式、亮度调节 |
| 简繁转换 | 简→繁 / 繁→简，可设转换范围 |
| 翻页 | 覆盖 / 仿真 / 滑动 / 无动画 / 滚动；翻页速度可调 |
| 操作 | 分区点击自定义（上/中/下三区九宫格，可分别设翻页/菜单/朗读）、音量键翻页、鼠标滚轮、自动翻页 |
| 进度 | 章节内进度、整书进度、页数页码、剩余时长估算 |
| 查找 | 章内查找、整书查找、跳转章节 |
| 内容处理 | 净化替换（正则）、标题去除重复、正文样式纠正、段落合并 |
| 书籍信息 | 详情页、目录、换源、编辑书名/作者/封面、书签、阅读记录 |

### 3. 书源引擎（核心）

| 能力 | 说明 |
|---|---|
| 规则引擎 | **CSS 选择器 / XPath / JSONPath / 正则 / JavaScript(Rhino)** 五种解析方式，可混用 |
| 规则类型 | 搜索规则、发现规则、详情规则、目录规则、正文规则、书评规则 |
| 网络层 | OkHttp + **Cronet**（Chromium 网络栈）、自定义 Header、CookieJar、DNS 覆盖、代理、并发限速 |
| 动态能力 | URL 里可写 `{{JS}}` 表达式、`@js:` 规则、`jsLib` 共享脚本、WebView 注入执行 |
| 书源管理 | 导入（本地/剪贴板/URL/二维码）、导出、分组、排序、批量启用、**后台校验**、逐条调试 |
| 附加 | 书源订阅（在线更新规则）、净化规则、TXT 目录规则、字典规则、朗读引擎规则 |
| 内置源 | 预置一条「轻小说文库」书源（详情/目录/正文可直读） |

### 4. 本地书籍

支持格式：**TXT / EPUB / MOBI / AZW3 / PDF / UMD**

- TXT：自动识别编码（ICU4J 探测 + meta 检测）、目录规则匹配、大文件分章
- EPUB：完整解析（含插图、注音、注释、内嵌样式、混合横竖排）
- MOBI：KF6 + KF8 双格式解析，自带解压与索引重建
- PDF：按页渲染为图，可翻页阅读
- UMD：老式手机电子书格式
- 文件管理：默认关联原文件（不复制），也支持导入到应用内；文件移动后可重新关联，保留进度与书签

### 5. 听书（本次新增）

| 能力 | 说明 |
|---|---|
| **Edge 在线音色** | 微软 Edge 大声朗读公开接口，无需账号/Key；协议校验算法已用独立实现交叉验证 |
| 音色 | 在线拉取（普通话 / 粤语 / 台湾国语 / 其他语言），单列 22 个内置音色做离线保底 |
| **自定义 SSML** | 留空用默认模板；可自定义 `<speak>` 结构、语速、音调、停顿 |
| 预缓存 | 边听边预合成后续段落 + 下一章前 10 段 |
| 锁屏控制 | MediaSession：通知栏、锁屏、耳机线控（上一章/下一章/上一段/下一段） |
| 倍速与定时 | 0.5~3 倍速、睡眠定时、段落跟随高亮 |
| 兜底 | 连续失败自动回落系统 TTS；也可直接用系统 TTS 或自建 HTTP TTS 引擎 |

- 分组、搜索（支持 `group:` 前缀过滤）

### 7. 视觉与主题

|---|---|

## 二、界面优势

### 1. 立体书架是第一眼差异点

绝大多数阅读器是平面的网格或列表。这里的书架是**真 3D 绘制**：

- 每本书画三面（书脊、顶面、封面），不是贴图旋转；
- 书脊厚度按书本真实体量错落，排成书架的弧形；
- 选中书会上浮并向左让出封面厚度，像真的从架上抽出来；
- 惯性吸附 + 触觉反馈，滑动手感接近物理书架；
- 但又**不牺牲实用性**：下方紧接完整列表，轮播只是入口不是全部。

这形成了"好看，但不只好看"的组合——很多带 3D 书架的 App 只有轮播没有清单，找书反而更难。

### 2. 底部虚线区是克制的结果

这次改动里，把原来 104dp 的"选中书信息块"（书名两行大字 + 作者/来源/章节数 + 页码）换成 46dp 的虚线框「全部图书 · N 本」。

好处：
- 轮播和列表之间的视觉噪音大幅下降，视线不会被挤在中间的密集文字打断；
- 虚线本身在传达"这是一层边界，下面是完整清单"，比一块实心信息卡更轻；
- 把 58dp 还给列表，一屏能多看到一本书。

### 3. 三级视觉重量，主次分明

- **阅读页**：全屏沉浸，菜单只在需要时浮出，玻璃面板半透明，不切断阅读沉浸感；
- **书架**：立体轮播做视觉主体，列表做操作主体，两者用一条虚线分隔；
- **设置**：纯列表 + 分组标题，不做花哨卡片，扫读效率优先。

三种场景三种密度，不会出现"整个 App 都在炫技"的疲劳感。

### 4. 主题系统是"能真正改出个人风格"的程度

不是给几套预设皮肤让你选，而是：

- 主色/强调色/背景/导航栏**逐项可调**；
- 莫奈取色能一键把壁纸色调搬到整个 App；
- 日间夜间分别配置，可存多套主题随时切；
- 阅读器还有**独立于 App 的一套配色**（读书时和逛书架时可以完全不同）。

对比很多阅读器"深色模式 = 把白底变黑底"，这里是真的能调出个人审美。

### 5. 性能分档是界面友好的关键

立体书架好看但吃性能。做法不是"要么全开要么全关"，而是三档：

| 设备 | 表现 |
|---|---|
| 低配（<3GB 或 ≤4 核或 isLowRamDevice） | 默认不显示轮播，关闭玻璃模糊，只留列表 |
| 中配 | 显示轮播，动效收敛，模糊 10px |
| 高配 | 全效果，模糊 18px |

并且给用户一个开关可以强行覆盖。**默认对低端机友好，但不剥夺高端机享受**——这是很多"重设计"App 栽跟头的地方。

### 6. 信息密度控制得当

- 列表项：封面 + 书名 + 作者 + 最近章节 + 更新时间 + 阅读进度条，一屏 8~10 本，不显局促；
- 网格项：封面为主，信息靠底，密度可调（2~5 列）；
- 详情页：封面、评分、简介、目录入口分层，不把长简介直接铺满。

### 7. 手势与快捷键考虑周全

- 阅读页九宫格分区点击，每区可独立设为翻页/菜单/朗读；
- 音量键翻页（朗读时也可用）；
- 长按选词、长按书架项出菜单、长按分组标签改名；
- 快滚条、下拉刷新、双击回顶部。

老用户能全键盘/全手势操作，新用户默认值也够用。

### 8. 说明文档做进了界面里

订阅页顶部有可折叠的使用说明（首次展开，之后记住你的选择）。这不是帮助文档外链，而是就地解释"这个页面的每一块是干什么的"。

阅读器的定制项极多，新手最容易卡在"这个功能在哪、怎么用"，把说明放在功能旁边，比藏在设置深处或官网要好。

## 三、和同类产品的差异

| 维度 | 常见阅读器 | 轻风阅读 |
|---|---|---|
| 书源 | 部分支持，或只支持固定几家 | 五种解析方式全支持，可自建可分享可校验可调试 |
| 书架 | 网格/列表 | 3D 立体轮播 + 网格/列表，且可按性能自动降级 |
| 听书 | 系统 TTS | Edge 在线音色 + 自定义 SSML + 预缓存 + 锁屏，失败回落系统 |
| 配色 | 几套预设 | 逐项可调 + 莫奈壁纸取色 + 多套主题保存 |
| 本地格式 | TXT/EPUB | TXT/EPUB/MOBI/AZW3/PDF/UMD |
| 数据 | 仅本机 | 完整备份 + WebDAV 云同步 + 远程书库 + 局域网/Web 服务 |
| 广告 | 大多有 | 无 |

## 四、当前已知不足（诚实列出）

1. **内置「轻小说文库」书源能力有限**：站点对未登录访客关闭了列表/搜索接口，这条源目前主要能打开已知书页链接（详情/目录/正文正常），站内搜索需要登录。
2. **立体书架底部虚线区与书距离偏近**：已记录在 `待办与问题记录.md`，等确认后调（预期拉开半个字高度）。
3. **竖排 / 对页未实现**：按要求不做，保持横排。
4. **玻璃拟态覆盖范围有限**：目前只做了阅读菜单，书架/发现/对话框仍是原样式。
5. **Edge 在线音色依赖微软服务**：服务调整或网络受限时会失败，已做系统 TTS 回落，但不能保证始终可用。
6. **莫奈取色在部分定制系统上取不到壁纸**：会静默保持原主题，不报错。
